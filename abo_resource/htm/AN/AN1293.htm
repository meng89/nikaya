增支部7集37經/朋友經第二(莊春江譯)
　　「比丘們！具備七法的比丘朋友應該被結交、應該被服侍、應該被侍奉，即使被排斥者，哪七個？是可愛者、合意者、尊重者、能被尊敬者、解說者、言語的容忍者、是作深的談論者，不在不正確處鼓勵，比丘們！具備這七法的比丘朋友應該被結交、應該被服侍、應該被侍奉，即使被排斥。」
　　「可愛者、尊重者、崇敬者，解說者與言語的容忍者，
　　　作深奧談論者，以及不在不正確處鼓勵者。
　　　凡這裡在人上，這些情況被發現，
　　　他是朋友：想要利益的憐愍者，
　　　即使被排斥者，像那類者應該被想要朋友者結交。」
AN.7.37/ 6. Dutiyamittasuttaṃ
　　 37. “Sattahi bhikkhave, dhammehi samannāgato bhikkhu mitto sevitabbo bhajitabbo payirupāsitabbo api panujjamānenapi. Katamehi sattahi? Piyo ca hoti manāpo ca garu ca bhāvanīyo ca vattā ca vacanakkhamo ca gambhīrañca kathaṃ kattā hoti, no ca aṭṭhāne niyojeti Imehi kho, bhikkhave, sattahi dhammehi samannāgato bhikkhu mitto sevitabbo bhajitabbo payirupāsitabbo api panujjamānenapī”ti.
　　“Piyo garu bhāvanīyo, vattā ca vacanakkhamo;
　　Gambhīrañca kathaṃ kattā, no caṭṭhāne niyojako.
　　“Yamhi etāni ṭhānāni, saṃvijjantīdha puggale;
　　So mitto mittakāmena, atthakāmānukampato.
　　Api nāsiyamānena, bhajitabbo tathāvidho”ti. Chaṭṭhaṃ.
