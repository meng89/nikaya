增支部5集178經/國王經(莊春江譯)
　　「比丘們！你們怎麼想它：這是否被你們看見或聽聞：『「這位男子捨斷殺生後，是離殺生者。」國王們捕捉他後，殺生的戒絕之因或殺或繫縛或驅逐或如需要做嗎？』」「大德！這確實不是。」「比丘們！好！這也沒被我看見或聽聞：『「這位男子捨斷殺生後，是離殺生者。」國王們捕捉他後，殺生的戒絕之因或殺或繫縛或驅逐或如需要做。』而是宣佈他的就像那樣惡業：『這位男子奪取男子或女子生命。』國王們捕捉他後，殺生之因或殺或繫縛或驅逐或如需要做。像這樣是否被你們看見或聽聞呢？」「大德！被我們看見與聽聞，以及將被聽聞。」
　　「比丘們！你們怎麼想它：這是否被你們看見或聽聞：『「這位男子捨斷未被給與的拿取後，是離未被給與的拿取者。」國王們捕捉他後，未被給與的拿取的戒絕之因或殺或繫縛或驅逐或如需要做嗎？』」「大德！這確實不是。」「比丘們！好！這也沒被我看見或聽聞：『「這位男子捨斷未被給與的拿取後，是離未被給與的拿取者。」國王們捕捉他後，未被給與的拿取的戒絕之因或殺或繫縛或驅逐或如需要做。』而是宣佈他的就像那樣惡業：『這位男子從村落或林野未被給與的拿取，被稱為偷盜的。』國王們捕捉他後，未被給與的拿取之因或殺或繫縛或驅逐或如需要做。像這樣是否被你們看見或聽聞呢？」「大德！被我們看見與聽聞，以及將被聽聞。」
　　「比丘們！你們怎麼想它：這是否被你們看見或聽聞：『「這位男子捨斷邪淫後，是離邪淫者。」國王們捕捉他後，邪淫的戒絕之因或殺或繫縛或驅逐或如需要做嗎？』」「大德！這確實不是。」「比丘們！好！這也沒被我看見或聽聞：『「這位男子捨斷邪淫後，是離邪淫者。」國王們捕捉他後，邪淫的戒絕之因或殺或繫縛或驅逐或如需要做。』而是宣佈他的就像那樣惡業：『這位男子在他人女子、他人少女處性交。』國王們捕捉他後，邪淫之因或殺或繫縛或驅逐或如需要做。像這樣是否被你們看見或聽聞呢？」「大德！被我們看見與聽聞，以及將被聽聞。」
　　「比丘們！你們怎麼想它：這是否被你們看見或聽聞：『「這位男子捨斷妄語後，是離妄語者。」國王們捕捉他後，妄語的戒絕之因或殺或繫縛或驅逐或如需要做嗎？』」「大德！這確實不是。」「比丘們！好！這也沒被我看見或聽聞：『「這位男子捨斷妄語後，是離妄語者。」國王們捕捉他後，妄語的戒絕之因或殺或繫縛或驅逐或如需要做。』而是宣佈他的就像那樣惡業：『這位男子以妄語破壞屋主或屋主之子的利益。』國王們捕捉他後，妄語之因或殺或繫縛或驅逐或如需要做。像這樣是否被你們看見或聽聞呢？」「大德！被我們看見與聽聞，以及將被聽聞。」
　　「比丘們！你們怎麼想它：這是否被你們看見或聽聞：『「這位男子捨斷榖酒、果酒、酒放逸處後，是離榖酒、果酒、酒放逸處者。」國王們捕捉他後，戒絕榖酒、果酒、酒放逸處之因或殺或繫縛或驅逐或如需要做嗎？』」「大德！這確實不是。」「比丘們！好！這也沒被我看見或聽聞：『「這位男子捨斷榖酒、果酒、酒放逸處後，是離榖酒、果酒、酒放逸處者。」國王們捕捉他後，戒絕榖酒、果酒、酒放逸處之因或殺或繫縛或驅逐或如需要做。』而是宣佈他的就像那樣惡業：『這位從事榖酒、果酒、酒放逸處的男子奪取男子或女子的生命；這位從事榖酒、果酒、酒放逸處的男子從村落或林野未被給與的拿取，被稱為偷盜的；這位從事榖酒、果酒、酒放逸處的男子在他人女子、他人少女處性交；這位從事榖酒、果酒、酒放逸處的男子以妄語破壞屋主或屋主之子的利益。』國王們捕捉他後，榖酒、果酒、酒放逸處之因或殺或繫縛或驅逐或如需要做。像這樣是否被你們看見或聽聞呢？」「大德！被我們看見與聽聞，以及將被聽聞。」
AN.5.178/ 8. Rājāsuttaṃ
　　 178. “Taṃ kiṃ maññatha, bhikkhave, api nu tumhehi diṭṭhaṃ vā sutaṃ vā– ‘ayaṃ puriso pāṇātipātaṃ pahāya pāṇātipātā paṭiviratoti. Tamenaṃ rājāno gahetvā pāṇātipātā veramaṇihetu hananti vā bandhanti vā pabbājenti vā yathāpaccayaṃ vā karontī’”ti? “No hetaṃ, bhante”. “Sādhu, bhikkhave! Mayāpi kho etaṃ, bhikkhave, neva diṭṭhaṃ na sutaṃ– ‘ayaṃ puriso pāṇātipātaṃ pahāya pāṇātipātā paṭiviratoti. Tamenaṃ rājāno gahetvā pāṇātipātā veramaṇihetu hananti vā bandhanti vā pabbājenti vā yathāpaccayaṃ vā karontī’ti. Api ca, khvassa tatheva pāpakammaṃ pavedenti – ‘ayaṃ puriso itthiṃ vā purisaṃ vā jīvitā voropesīti. Tamenaṃ rājāno gahetvā pāṇātipātahetu hananti vā bandhanti vā pabbājenti vā yathāpaccayaṃ vā karonti. Api nu tumhehi evarūpaṃ diṭṭhaṃ vā sutaṃ vā’”ti? “Diṭṭhañca no, bhante, sutañca suyyissati cā”ti.

漢巴經文比對(莊春江作)：
　　「或如需要做」(yathāpaccayaṃ vā karontī'ti，逐字譯為「如+緣-或-作」)，菩提比丘長老英譯為「依情況的需求處理他」(or do with him as the occasion demands)，或「或其他懲罰」(or otherwise penalize)，或「依他們的願望處理它們」(doing with them as they wish, SN.22.33)。
